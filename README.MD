# SauceDemo UI Automation

## Технологии

- Java 17
- Gradle (Kotlin DSL)
- JUnit 5
- Selenide 7.18.0
- Allure Reporting
- Selenide Video Recorder (встроенный)

## Покрытые сценарии

- Авторизация (валидные и невалидные пользователи, параметризованный тест)
- Просмотр товара
- Добавление товара в корзину
- Удаление товара из корзины
- Оформление заказа
- Выход из аккаунта

## Требования

- JDK 17
- Браузер Google Chrome
- FFmpeg (для записи видео при падении тестов)

## Запуск тестов

```bash
gradle test
